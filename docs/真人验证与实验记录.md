# 真人验证与实验记录

## 首次验证（约10分钟）

开启软件并校准，先看指标变化，不急于评价准确率。

1. 正视屏幕10秒，记录俯仰、歪头、肩线的相对角度。
2. 缓慢低头：确认俯仰正向增加；抬头：确认负向变化。若方向相反，停止调阈值，先修正角度约定。
3. 左右歪头，确认歪头角绝对值增加，保持12至15秒触发提醒，恢复后等待3秒以上。
4. 保持头部尽量水平，分别抬高一侧肩，检查肩部角度与提醒；这只能验证肩线变化，不证明能区分异常肩部和有意抬手。
5. 持续低头并歪头，确认两项同时异常，恢复其中一项时另一项不被清除。
6. 短暂看键盘、转头、喝水、移动椅子、耸肩、坐低、弯腰，记录误判。
7. 遮住肩或脸，检查相关项目显示无法判断；移出画面后不能延续报警计时。
8. 暂停、继续、重新校准、结束，核对报告与CSV。

## 参与者与采集

目标5—8名自愿参与者；明确说明使用目的、保存字段、是否录制、保存时间和删除方式，取得同意后再采集。使用P01等编号，不写学校、姓名或面部身份信息到对外报告。

开发组用于调阈值，最终测试组按参与者完全隔离。模型版本、参数冻结后才评估测试组。不要使用测试反馈持续调参后仍把同一批数据称作独立测试。

每人采集三项单独动作、组合动作、正常学习及干扰动作。每个持续事件建议15秒，正常片段用于累计每小时误提醒。记录实际时长与条件，不用短时间零误报推断长期性能。

标注三个独立标签（正常/偏离/无法判断）和开始结束时间；真实标签依据录像/动作指令复核，不按算法自己的角度阈值生成。边界不明确标无法判断，说明排除范围。

## 对照版本

A：固定阈值（无个人校准、无持续过滤）。
B：个人校准（保留相同模型，去掉持续过滤）。
C：个人校准＋持续过滤（最终软件）。

同一输入、相同置信度门槛、相同通知冷却口径，分别报告覆盖率、误提醒、检出率与延迟。即时版本与持续版本的触发等待不同，延迟单独报告，不能混成“精度”比较。

## 指标定义

- 持续事件检出率：可评价且至少持续10秒的真实偏离事件中，期间出现对应alert的比例。分别列三项。
- 误提醒/小时：正常或不应提醒片段中的提醒次数除以这些片段的时长（小时）；同时公布无法判断时长。
- 有效覆盖率：该项有效时长除以要求监测的总时长，暂停排除，识别失败不排除。
- 提醒延迟：真实事件开始到对应提醒的时间；另报扣除设定等待时间后的额外延迟。
- P95更新延迟：采集时间到GUI处理结果，不包括设计上的提醒等待。
