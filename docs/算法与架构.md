# 坐伴算法与软件架构

## 产品定位

单人、正面电脑摄像头、本地推理。输出低头、歪头、肩部倾斜三个独立状态。可同时出现，不提供疾病诊断，不评估头前伸或脊柱。

## 数据流

摄像头采集线程 → 最新帧邮箱 → 推理线程（人脸模型＋Pose Lite） → 最新结果邮箱 → GUI定时消费 → 校准／判定 → 提醒＋SQLite → 会话报告。

两个邮箱均只保存最新结果，不使用无界队列。所有数据库操作在GUI线程执行，每秒提交，结束会话立即提交。非正常退出下次启动标记interrupted；可能丢失最后约1秒未提交数据，不补造数据。

## 模型与角度

使用MediaPipe Tasks VIDEO模式与CPU delegate，时间戳单调递增；不使用旧版solutions接口。固定模型版本1，SHA-256见models/manifest.json。模型文件以字节缓冲区加载，避免Windows中文路径导致原生库文件读取异常。

人脸模型输出变换矩阵，取左上3×3并用SVD极分解移除尺度。使用R=Rz(roll)Ry(yaw)Rx(pitch)分解，pitch=atan2(R21,R22)，yaw=atan2(-R20,sqrt(R00²+R10²))，roll=atan2(R10,R00)。假定模型相机坐标Y向上、脸朝+Z时，正pitch为向下转。数学角度符号已通过合成旋转矩阵测试，实际人脸动作符号及泛化性能仍待真人验证。

肩部使用11、12号关键点，要求visibility和presence均不小于0.65、点位在图像内。坐标乘以宽高还原像素，再按画面左右排序，用atan2(dy,dx)计算肩线角度。肩宽小于图像宽10%时不判断。

鼻尖到肩线的垂直距离除以肩宽，得到无量纲实验指标。它会受耸肩、身体转向等影响，当前不参与低头判断。只有同意采集的真人对照实验表明它改善误判后，才修改算法版本引入。

显示时镜像画面，计算始终基于未镜像画面。界面不输出容易混淆的左右侧诊断，仅显示角度变化及异常种类。

## 校准与质量控制

连续5秒、至少25组有效测量（平均每秒5组），头部侧转绝对值不超过25°，三项都有效。取角度中位数为参考；头部角度标准差超过3°或肩线超过2°则重试。采样中断超过0.5秒或任一项无效会重新积累。缩短窗口可能让参考值更受短时波动影响，需通过真人复测观察误报和重复校准差异。

正常监测时头部相对校准yaw超过30°则两项头部检测无效。脸和肩采用独立有效性，肩部遮挡不会强制使人脸结果无效。人脸检测/存在/跟踪置信度设为0.6。单人使用是前提，不支持多人身份跟踪。

## 状态机

每项：unknown → normal → pending → alert；还可进入paused。

角度先计算相对参考的最短角差，再用时间常数0.5秒的指数平滑。低头只判断正向偏差，歪头和肩线判断绝对偏差。新默认进入阈值10°/8°/6°，退出阈值6°/5°/3°；可在设置页单独调整并验证退出值小于进入值，均不是医学阈值。旧版完整默认角度配置会迁移，已自定义的角度配置保留。

超过进入阈值连续5秒进入alert；pending期间回到进入阈值以内重置计时。alert后回到退出阈值以内连续3秒才恢复，处于阈值中间时保持状态。同类提醒间隔至少60秒，暂停/遮挡重置持续计时但保留提醒冷却。无效或0.5秒以上旧结果不参与判断。

## 本地存储与接口

- Measurement：单调时间戳、pitch/roll/shoulder可空数值、yaw、实验距离比、无效原因。
- Engine结果：三项states、平滑后的deltas、reasons、当次notices。
- sessions：开始UTC时间、完成状态、算法版本、校准参数、配置快照。
- samples：会话、单调时间、状态/指标/提醒JSON，不存图像。
- settings：本地配置，启动验证参数，非法时恢复默认。
- day_stats：按本机日期汇总每次会话的有效时长、持续偏离与提醒，跨午夜分段，供月历快速读取。
- journey_completions：每个本地日期最多一条已解锁关卡；仅新版启用趣味功能的会话参与解锁，旧会话只显示在日历。

数据目录默认来自当前用户的LOCALAPPDATA，可在启动时用`--data-dir`覆盖。应用锁阻止同数据目录的第二实例干扰运行中的会话。CSV导出UTF-8 BOM，时间为相对会话秒，包含角度偏差、距离比、无效原因和更新延迟。原始系统路径不写入对外实验结论。

## 统计口径

相邻结果积分，单个结果最多覆盖0.5秒。normal、pending、alert均计入该项有效时间；unknown、paused不计。持续偏离时长只计算alert阶段，不追溯pending的5秒。总偏离取三项alert时间的并集，不能相加。各项占比必须用该项有效时间作分母。图表显示未知/暂停，避免隐瞒识别失败。

七站旅程的目标依次为15、20、25、20、25、20、15分钟。站点只依据当日有效监测时间解锁，每天最多一站；提醒与偏离时长不会影响奖励。七站完成后进入下一轮。按日汇总首次升级时从旧样本建立索引，不追溯发放奖励。月历标记仅表示使用或完成关卡，不代表医学意义上的“正确坐姿”。

## 已知限制

相机角度改变不会可靠自动检出，需要用户重新校准；校准无法证明参考姿势符合医学要求。长时间抬手、身体转向、相机倾斜可能影响肩部；俯仰估计受人脸形状和遮挡影响。短暂看键盘可被持续门槛过滤，但长时间写字是否应提醒取决于使用场景，用户可暂停。
