# 坐伴 · ZuoBan

使用普通电脑摄像头，在本地检测持续低头、歪头和肩部倾斜，并提供姿态提醒与会话统计的Windows桌面应用。

> **开发状态：早期原型。** 当前支持CPU推理，默认不保存或上传摄像头画面。真实场景的识别效果和跨设备兼容性仍在验证，检测结果仅用于姿态变化提示，不用于医疗诊断。

## 功能

- **三项姿态检测**：低头、歪头和肩部倾斜分别判断，可同时提示。
- **个人校准**：采集10秒参考姿态，减少不同机位和个人差异的影响。
- **持续提醒**：默认偏离持续10秒后提醒，支持声音开关、音量和等待时间设置。
- **会话报告**：查看有效监测时间、持续偏离时间、提醒次数和状态时间线，导出CSV。
- **本地运行**：无需账号或云端服务，无独立显卡也可使用。

## 快速开始

获取仓库源码后，在项目根目录打开PowerShell。

### 1. 安装依赖

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
```

锁定依赖包含运行、测试及文档工具。OpenCV使用 `opencv-contrib-python`，不要再同时安装 `opencv-python`，以免两者共用的文件发生冲突。

### 2. 下载模型

```powershell
.\.venv\Scripts\python.exe tools\download_models.py
```

模型来自Google官方存储，权重不包含在Git仓库内。下载地址、版本和SHA-256记录见 [模型清单](models/manifest.json)。

### 3. 启动应用

```powershell
.\.venv\Scripts\python.exe main.py
```

依赖和模型准备完成后，后续使用只需执行启动命令。修改源码后重新启动程序即可。

## 使用方法

1. 点击**开启摄像头**，调整屏幕角度和光线，让脸与双肩完整入镜。
2. 面向屏幕、自然坐直，点击**校准并开始监测**，保持稳定10秒。
3. 监测时查看三项状态。短暂动作不会立即提醒；持续偏离后会显示提示，并按设置播放声音。
4. 需要暂时离开监测时点击**暂停**；暂停期间摄像头预览仍开启。
5. 点击**结束会话**关闭摄像头，在**会话报告**中选择记录查看结果或导出CSV。

每次重新开启监测或调整摄像头、屏幕角度后，都应重新校准。校准只建立个人参考，不代表对姿势是否符合医学标准的认证。

## 数据与隐私

- 摄像头画面在本机处理，默认不录制、不上传。
- 本地记录包括姿态数值、状态、提醒事件、校准参数和会话统计。
- 默认数据库位置为 `%LOCALAPPDATA%\ZuoBan\zuoban.sqlite3`；可在设置页清除会话记录。
- CSV导出包含数值与事件，不包含摄像头画面。分享问题记录前，请移除个人信息。
- 可通过 `--data-dir` 指定独立数据目录，例如用于测试：

```powershell
.\.venv\Scripts\python.exe main.py --data-dir output\test-data
```

## 检测方式与限制

低头和歪头依据人脸朝向估计；肩部倾斜依据双肩连线在画面中的角度。鼻尖到肩线的归一化距离仅作为实验指标记录，不参与低头报警。

| 检测项目 | 偏离阈值 | 恢复阈值 |
|---|---:|---:|
| 低头 | 15° | 10° |
| 歪头 | 12° | 8° |
| 肩部倾斜 | 8° | 5° |

以上角度均相对于个人校准值，是待实测调整的工程参数。默认持续偏离10秒后提醒，回到恢复范围内持续3秒解除，同类声音提醒间隔至少60秒。

- 当前面向单人、正面使用场景；多人、遮挡、弱光和大幅侧转可能影响结果。
- 耸肩、抬手、身体转向或改变机位可能影响肩部判断。
- 无法可靠检测时，相关项目显示“无法判断”，不计入该项有效监测时间。
- 不检测头前伸，也不诊断高低肩、颈椎或脊柱问题。
- 目前没有可对外宣称的真人识别准确率、长期健康效果或全设备兼容性结论。

## 常见问题

**摄像头无法打开**

检查Windows相机隐私设置，关闭占用相机的软件。若有多个设备，在设置中尝试其他摄像头编号，保存后重新开启。

**校准一直重新计时**

确认脸与双肩完整可见，保持正面、光线均匀，并连续稳定10秒。遮挡、动作变化或有效采样不足会使校准重新开始。

**提示模型缺失**

运行模型下载脚本，确认 `models/` 中包含 `face_landmarker.task` 和 `pose_landmarker_lite.task`。

**修改代码后exe没有变化**

已有exe是独立构建的版本，不会自动读取修改后的源码。开发时使用Python启动命令；源码验证稳定后再构建新版本。
